# Интеграция с 1С и CommerceML

## Этапы MVP

1. **Экспорт файлов**
   - Генерация XML КС-2/КС-3/М-29 по утверждённым XSD.
   - Пакет CommerceML с позициями сметы и ресурсами.
   - Выгрузка осуществляется на мобильном устройстве и может быть отправлена по электронной почте или сохранена в сетевую папку.
2. **Импорт в 1С**
   - Стандартная обработка в 1С загружает XML и формирует документы закрытия.
   - Валидация выполняется на стороне 1С, ошибки возвращаются пользователю.

## Расширение (следующие релизы)

- Двусторонний обмен через HTTP/OData: мобильное приложение отправляет фактические объёмы, 1С возвращает статусы оплаты.
- Синхронизация справочников контрагентов, объектов и договоров.
- Поддержка электронных подписей и отметок об отправке в ГИС ЖКХ.

## Форматы

- `commerce.xml` — пакет CommerceML с каталогом ресурсов, предложений и заказом.
- `ks2.xml`, `ks3.xml`, `ks6a.xml`, `ssr.xml` — документы по XSD Минстроя.

Примеры XSD будут добавлены в `schemas/` вместе с контрактными тестами.
