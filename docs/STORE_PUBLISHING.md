# Публикация в сторах

## Google Play

1. Собрать `appbundle` (`flutter build appbundle`).
2. Загрузить в Google Play Console, заполнить карточку приложения.
3. Добавить описание оффлайн-функций и соответствия нормативным требованиям.
4. Предоставить видео/скриншоты: мастер сопоставления, детали сметы, экспорт документов.
5. Ответить на вопросы Data Safety и указать использование шифрования.

## App Store

1. Собрать `ipa` через `flutter build ipa`.
2. Использовать Transporter для загрузки, заполнить App Store Connect.
3. В разделе Compliance подтвердить использование шифрования.
4. Подготовить Privacy Policy с описанием обработки данных.

## Общие требования

- Тестовые учётные записи для ревьюеров.
- Документация по оффлайн-режиму и политике поддержки.
- Регулярные обновления: патчи безопасности, нормативные базы, улучшения UX.
