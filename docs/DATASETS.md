# Наборы данных

Каждая версия набора нормативов хранится в `datasets/<version>/` и содержит:

- `meta.json` — описание версии, дата публикации и назначение.
- `norms.jsonl` — строки JSON с основными атрибутами нормы (код, название, раздел, единица, пояснение).
- `indices.json` — массив индексов Минстроя по регионам и датам.
- `coeff_matrix.json` — совместимость коэффициентов, диапазоны и бизнес-правила.
- `synonyms.json` — словари синонимов для NLP-пайплайна.

## Импорт внешних источников

1. **XML/АРПС** — парсинг с помощью XSD-схем для валидации, конвертация в `norms.jsonl`.
2. **XLSX** — использование скриптов импорта на Node.js/Python (будет добавлено) для трансформации колонок в унифицированный формат.
3. **Базы ФСНБ** — конвертация с сохранением техчасти и ссылок на классификаторы ресурсов.

Каждый импорт проходит нормоконтроль: проверка единиц измерения, поиск дубликатов, валидация коэффициентов. Скрипты импорта и тесты будут опубликованы в `tools/`.

## Версионирование и обновления

- Новые версии публикуются как `datasets/vX/` с `meta.json`, содержащим ссылку на официальное издание.
- Мобильное приложение хранит текущую версию локально и применяет дельта-обновления.
- Бэкенд служит источником правды и подписывает обновления для клиентов.
